# PuppyBot6 - Standalone Color Lab (โปรแกรมทดสอบและคาลิเบรตเซนเซอร์สี)

โฟลเดอร์นี้ถูกแยกออกมาเป็นโปรเจกต์อิสระ **สำหรับทดลองอ่านค่าสีและคาลิเบรตเซนเซอร์สีโดยเฉพาะ** โดยไม่ไปยุ่งเกี่ยวกับโค้ดหลักของหุ่นยนต์ (`src/main.ino`) 

---

## 🌟 จุดเด่นของโปรแกรมนี้
- **ใช้เฉพาะไลบรารีของ Adafruit**: 
  - `Adafruit_TCS34725` (เซนเซอร์อ่านค่าสี I2C)
  - `Adafruit_ST7735` + `Adafruit_GFX` (จอแสดงผลสี IPS/TFT SPI)
  - `Wire` (I2C Bus สำหรับเซนเซอร์หน้า และ เซนเซอร์ข้าง)
  - `EEPROM` (บันทึกค่าที่เทียบสีแล้วลงหน่วยความจำถาวร)
- **ไม่โหลดโมดูลที่ไม่จำเป็น**: ไม่มีโค้ดมอเตอร์, ไจโร IMU, หรือเส้นทางวิ่งใดๆ เบาและรวดเร็ว
- **หน้าจอ UI กราฟิกสวยงาม**: มีแถบวัดค่าสี RGB แยกช่อง (0-200), ป้ายสเตตัสสีสดใส, Lux, CCT, และกล่องแสดงผลสีแบบ Real-time
- **ระบบเสียง Buzzer**: มีเสียงปี๊บตอบรับเมื่อกดปุ่ม, เสียงเตือนเมื่อเปลี่ยนสี, และเสียงยืนยันเมื่อบันทึกค่าสำเร็จ
- **รองรับทั้งโหมด 1 ปุ่ม และ 4 ปุ่ม**:
  - สวิตช์ปุ่มกดบนบอร์ด (Pin 3)
  - หรือ ปุ่มภายนอก: `[B1]=ADC15`, `[B2]=Pin 37 (UP)`, `[B3]=Pin 38 (OK)`, `[B4]=Pin 39 (DOWN)`
- **รองรับทั้งเซนเซอร์สีพื้นหน้า (Front) และเซนเซอร์สียื่นข้าง (Side)** สามารถกดสลับดูได้ในเมนูทันที

---

## 📋 เมนูฟังก์ชันการทำงาน

1. **`1. LIVE COLOR TEST`** (ทดสอบอ่านค่าสีสด):
   - แสดงกล่องสีขนาดใหญ่ตรงกลางพร้อมชื่อสีภาษาอังกฤษ (`RED`, `GREEN`, `BLUE`, `YELLOW`, `WHITE`, `BLACK`)
   - แสดงแถบมิเตอร์ R, G, B Normalized (0-100%) แบบ Real-time
   - แสดงค่า Lux ความเข้มแสงสะท้อน และ Color Temperature (K)
   - ส่งออกข้อมูลทาง Serial Monitor (115200 bps) ไปพร้อมกัน
   - ส่งเสียงปี๊บเมื่อเปลี่ยนสี

2. **`2. CALIBRATE 6 COLORS`** (เข้าสู่กระบวนการเทียบค่าสีทีละสี):
   - เทียบค่าสี 6 สี: แดง, เขียว, น้ำเงิน, เหลือง, ขาว, ดำ
   - แสดงตัวอย่างสีก่อนบันทึก
   - กดปุ่ม `[OK]` เพื่อแคปเจอร์และบันทึกลง EEPROM อัตโนมัติ

3. **`3. VIEW CALIB TABLE`** (ดูตารางค่าสีที่บันทึกไว้):
   - แสดงตารางสรุปค่า R, G, B ของแต่ละสีที่จำอยู่ในหน่วยความจำ EEPROM

4. **`4. RAW INSPECTOR`** (ส่องดูค่าดิบ):
   - ดูค่าดิบ Raw Clear, Raw Red, Raw Green, Raw Blue จากชิป TCS34725
   - ดูค่า Lux และ Color Temp เพื่อเช็กฮาร์ดแวร์และสภาพแสงแวดล้อม

5. **`5. SWITCH FRONT/SIDE`** (สลับเซนเซอร์):
   - สลับระหว่างเซนเซอร์พื้นสนาม `[FRONT]` (Wire SDA=4, SCL=5) กับ เซนเซอร์สียื่นข้าง `[SIDE]` (Wire1 SDA=6, SCL=7)

---

## 🚀 วิธีการอัปโหลดโค้ดลงบอร์ด

1. เสียบสาย USB เข้ากับบอร์ด PuppyBot6
2. ดับเบิ้ลคลิกไฟล์ `upload.bat` ภายในโฟลเดอร์นี้ (`color_test_lab/upload.bat`)
3. หรือพิมพ์คำสั่งใน Terminal:
   ```bash
   cd color_test_lab
   pio run -t upload
   ```
