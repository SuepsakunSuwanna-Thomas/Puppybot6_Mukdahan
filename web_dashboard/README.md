# 🚀 PuppyBot6 Web Serial Mission Control & Diagnostics Lab

ระบบหน้าเว็บควบคุมและทดสอบหุ่นยนต์ PuppyBot6 ผ่าน Web Serial API (COM Port) แบบ Real-time ความเร็วสูง 115200 Baud

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **เชื่อมต่อโดยตรงผ่าน Web Serial API (COM Port):**
   - ใช้งานได้บน Google Chrome, Microsoft Edge, Opera (ไม่ต้องติดตั้งโปรแกรมหรือไดรเวอร์เสริม)
   - เชื่อมต่อและตัดการเชื่อมต่อได้ทันที พร้อมปุ่ม **EMERGENCY STOP** หยุดฉุกเฉินทุกมอเตอร์

2. **ระบบ Telemetry ข้อมูลเซนเซอร์สดๆ (Real-time):**
   - **TCS34725 Color Sensors**: แสดงชื่อสีที่ตรวจพบทั้งหน้าและหลัง พร้อมมิเตอร์อัตราส่วน R, G, B
   - **14-Channel Line Sensors**: ไฟ LED จำลอง 7 ดวงหน้า (A0-A6) และ 7 ดวงหลัง (A7-A13) สว่างเมื่อเจอดำ พร้อมตรวจจับเส้นตัด (Crossing)
   - **Navigation & Environment**: ระยะ IR GP2Y0A41SK0F (cm), ระยะ Encoder (cm), องศาไจโร IMU Yaw พร้อมเข็มทิศ, และสถานะสวิตช์

3. **ห้องทดสอบ PID & Line Following (PID Test Lab):**
   - เลือกฟังก์ชันที่ต้องการทดสอบ:
     - `Fline_by_phase` (ตามเส้นกำหนดระยะทาง cm)
     - `Fline_by_pass` (ตามเส้นผ่านแยกตามจำนวนเส้น)
     - `Fline_by_time` (ตามเส้นกำหนดเวลา ms)
     - `turnLeft` / `turnRight` (เลี้ยวซ้าย/ขวาที่แยก)
     - `Fline_by_phase_B` / `Fline_by_pass_B` (ถอยหลังตามเส้น)
     - `turnLeft_B` / `turnRight_B` (ถอยหลังเลี้ยว)
     - `checkLine` / `checkLine_B` (จัดกึ่งกลางเส้น)
     - `Follow_Notline` / `Backword_Notline` (วิ่งตรงไม่ดูเส้น)
   - ตั้งค่าความเร็ว (Speed: 10 - 100%)
   - ตั้งค่า **Line KP** (0.1 - 6.0) ปรับแต่งได้สดๆ
   - **กลไกความปลอดภัย (Wait for Switch):** หุ่นยนต์จะส่งเสียงปี๊บเตือนและรอกดสวิตช์ที่ตัวหุ่นก่อน จึงจะเริ่มวิ่ง เพื่อให้ผู้ใช้มีเวลาวางหุ่นบนสนาม

4. **ห้องทดสอบมอเตอร์ 4 ล้ออิสระ (4WD Motor Diagnostics):**
   - สไลเดอร์ปรับความเร็วและทิศทางแยก 4 ล้อ: M1 (หน้าซ้าย), M2 (หน้าขวา), M3 (หลังซ้าย), M4 (หลังขวา) (-100 ถึง +100)
   - ปุ่มลัดทิศทาง 4 ล้อ: เดินหน้า, ถอยหลัง, สไลด์ซ้าย, สไลด์ขวา, เลี้ยวซ้าย, เลี้ยวขวา, หยุดทั้งหมด
   - ปรับชดเชยล้อ (Motor Trim M1..M4) และ Battery Compensation (Speed Offset %)

5. **ห้องตั้งมุมเซอร์โวมอเตอร์ (Dual Servo Angle Lab):**
   - เซอร์โว 1 (มือจับ/หน้า): สไลเดอร์ 0° ถึง 180° พร้อมปุ่มลัดมุมใช้งาน
   - เซอร์โว 2 (แขนช่วย/หลัง): สไลเดอร์ 0° ถึง 180° พร้อมปุ่มลัดมุมใช้งาน
   - ตัวเลือกรอกดสวิตช์ หรือหมุนทันที

6. **Serial Terminal & Raw JSON Console:**
   - หน้าต่างแสดง Log ข้อความเข้า-ออก (TX / RX)
   - ช่องส่งคำสั่ง JSON โดยตรง

## 🛠️ วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ Batch (ง่ายที่สุด)
ดับเบิ้ลคลิกที่ไฟล์:
```
d:\puppybot6_Mukdahan\web_dashboard\start_dashboard.bat
```
*(ระบบจะรัน Local Server และเปิดหน้าเว็บ `http://localhost:8000` บนเบราว์เซอร์ให้อัตโนมัติ)*

### วิธีที่ 2: รันผ่านคำสั่ง Python
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
python server.py
```
